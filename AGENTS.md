# GitHub profile

`README.md` renders on github.com/mooktakim because the repo name matches the
username. This repo is public, so never add private information here.

This repo is an output of `../career`, the private source of truth. Career
facts, dates and the headline come from `../career/record/`, and the agreed
content is in `../career/outputs/github.md`. To change a career fact, change it
in `../career` first.

To publish, edit `README.md`, commit, and push to `main`. Changes appear within
a minute. The list between the `BLOG-POST-LIST` markers is written by
`.github/workflows/blog.yml`, so do not edit it by hand. The full conventions
are in `../mooktakim-com/AGENTS.md`, under "GitHub Profile README".
